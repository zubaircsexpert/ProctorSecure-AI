# Chat Feature - Quick Guide (اردو/English)

## 🎯 Kya Features Hain?

### 1️⃣ **Responsive Design - Mobile Par Bilkul Responsive**
- 📱 Mobile: Full screen chat (bilkul poora screen)
- 💻 Laptop: Single screen par poora dikhai (sidebar + chat)
- 📊 Tablet: Half-half split view

### 2️⃣ **Security Code System - Pehli Dafa Chat Karte Time**
```
Pehli Dafa:
┌─────────────────────────────┐
│  Student → Teacher ko code  │
│  Code: ABC123 (6 digits)    │
│  Teacher ko same code dena  │
│  → Chat verify ho gaya ✅   │
└─────────────────────────────┘

Doosri Dafa:
┌──────────────────────────────┐
│ Code de -> Chat khul gaya    │
│ Code salah ho to error 🔒    │
└──────────────────────────────┘
```

### 3️⃣ **Message Seen - Blue Tick**
```
⏱️  = Bhej rahe ho (sending)
✓   = Bhej diya (sent)
✔️  = Para liya (seen) - BLUE TICK
```

### 4️⃣ **Last Seen Online**
```
"Online now"  - Abhi online hai
"5m ago"      - 5 minute pehle
"2h ago"      - 2 ghante pehle
"3d ago"      - 3 din pehle
```

### 5️⃣ **Specific Student ↔ Specific Teacher**
- Har student ke liye specific teacher hai
- Har teacher ke liye specific students hain
- Dusre students/teachers ko nahi dekh sakta

## ❓ Common Questions

### Q: Code kaha likha tha?
**A:** Golden/yellow box mein likha hota hai pehli dafa. Screenshot le lo ya kagaz par likho.

### Q: Code bhool gya?
**A:** Naya chat shuru karo, naya code milega.

### Q: Message dikhai nahi de rahe?
**A:** Chat verify karo pehle. Lock icon 🔒 dekho? Code zaroori hai.

### Q: Last seen "never online" kyon dikhai de rahe?
**A:** Agar dono online nahi hain to ye dikhai deta hai.

### Q: Kya mobile par bhi full responsive hai?
**A:** Haan! Poori screen cover karta hai mobile par.

### Q: Kya dusre students ko dekh sakta hun?
**A:** Nahi! Sirf apne teacher/students ko dikhai deta hai.

## 📞 Troubleshooting

```
Problem: Chat verify nahi ho rahe
Solution: Code sahi likho (uppercase automatically)

Problem: Messages bheja nahi ja rahe
Solution: Pehle chat verify kro (code enter kro)

Problem: UI responsive nahi hai
Solution: Browser refresh kro (F5 or Ctrl+R)

Problem: Last online nahi update ho rahe
Solution: 10 second wait kro, phir page refresh

Problem: Code nahi dikhai de rahe
Solution: Pehli dafa "New" chat karoge to dikhai dega
```

## 🌟 Tips & Tricks

   - Ctrl+Enter daba -> Message bhej jata hai

5. **Agar Busy Ho**

   - Pata chal jaega kaun online tha
